POPUP PREVENTION · 0.1.0

Stop ad tabs before they open.

Checks new-window destinations against a shared popup-ad list. Works alongside uBlock Origin, using its own list rather than reading uBlock’s settings.

Protection

Stops empty windows that may become ads later. Can also affect sign-ins and downloads.

For persistent popups with unknown destinations. Allowed destinations below still work; ordinary links remain governed by the ad list.

Exceptions

The address in the main browser tab, including its embedded players. Enter one domain per line; subdomains are included.

Blocking list

Defaults to HaGeZi’s Pop-Up Ads list. Updates daily. A bundled copy works offline. HTTPS, one domain per line; full uBlock/EasyList syntax is not supported.

One domain per line. Checks match hostnames, never unrelated words in the URL.

What to expect

Reload open pages after installing. Known ad URLs are suppressed before a new window is created. Blank windows are allowed by default because their future destination is unknown.

Very early scripts can run before settings finish loading. Redirects, browser menu commands, and scripts that deliberately bypass or replace the hook can still escape. This is an experimental extension, not a guarantee of zero popups.

No analytics or browsing logs. Checks happen locally. Automatic list updates contact the list host without sending browsing URLs.
